# Cozy Family Circle

Build a warm, personal family chat app for 4 family members, styled in a "Cozy Dusk" theme.

Authentication

1.Each family member signs up individually with their own email address and password

2.Email verification is required — users must click a confirmation link before accessing the app

3.After verifying, the user selects/confirms their profile (name + avatar)

4.Users can set or change their profile picture anytime — either upload a new photo or choose one directly from the shared family Gallery

5. Returning users log in with email + password

6. Include a "Forgot password" flow — user requests a reset link via email and sets a new password

Chat

1.Real-time group chat shared by all 4 members

2.Send text messages, photos, and videos, shown as previews/thumbnails that expand on tap

3.Emoji reactions on messages and photos

4.Read receipts / "seen by" indicators

5.Search messages and media by keyword or date

Gallery

1.Dedicated "Gallery" tab collecting all shared photos/videos into a chronological timeline

2.Favorite/star photos without deleting others

Design — "Cozy Dusk" theme

1.Palette: deep plum, warm coral, soft lavender, blended in gentle gradients (like a sky just after sunset)

2.Background: soft gradient mesh, not flat white/gray — subtle enough to stay in the background

3.Distinctive warm accent font for names/headers, paired with a clean readable body font

4.Soft, organic shapes — blobs, curves, and slightly tilted photo frames instead of plain rectangles

5.Custom empty states with warm, personal micro-copy (e.g. "Your family's story starts here")

6.Subtle micro-animations — reactions float gently, photos fade and scale in on load

7.Chat bubbles: coral for sent messages, soft lavender for received, rounded organic edges

8.Mobile-first, fully responsive layout

9.No enterprise/SaaS visual patterns — this should feel like an intimate digital scrapbook, not a productivity tool

## Development

```sh
git clone <this-repository-url>
cd <repository-name>

```
